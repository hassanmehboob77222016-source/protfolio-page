# Hassan Mehboob — Portfolio

Agentic AI Developer portfolio built with HTML, TailwindCSS, and vanilla JavaScript.

## Features

- 🎨 Dark/Light theme toggle
- ✨ Animated neural network background
- 📬 Contact form (powered by FormSubmit)
- 📱 Fully responsive design
- ⚡ Single-page navigation

## Deploy

This is a static site — just push to GitHub and enable **GitHub Pages** from Settings → Pages → Branch: `main` → Folder: `/ (root)`.

## Live

> Your site will be live at `https://<your-username>.github.io/<repo-name>/`
